# 第5部分：术语注册、查询服务 字段说明

**标准编号**: WS/T 846.5-2024

## 服务列表

| 服务名称 | 交互标识符 | 说明 |
|---------|-----------|------|
| 术语注册服务 | PRVS_IN000001UV01 | 用于新术语信息的注册 |
| 术语更新服务 | PRVS_IN000002UV01 | 用于已注册术语信息的更新 |
| 术语查询服务 | PRVS_IN000003UV01 | 用于查询术语信息 |

## 字段说明

### 消息头（公共部分）

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| messageHeader.id.root | 消息流水号根标识 | string | 是 | 固定值 2.16.156.10011.2.5.1.1 |
| messageHeader.id.extension | 消息流水号 | string | 是 | 消息唯一标识，最大50字符 |
| messageHeader.creationTime | 消息创建时间 | datetime | 是 | 格式：yyyyMMddHHmmss |
| messageHeader.interactionId.extension | 服务标识 | string | 是 | 具体服务标识代码 |
| messageHeader.processingCode | 处理代码 | string | 是 | D-调试/P-产品/T-训练 |
| messageHeader.acceptAckCode | 应答控制码 | string | 是 | AL-总是/ER-仅错误/NE-从不 |

### 术语注册请求

| 字段路径 | 字段名称 | 类型 | 必填 | 长度 | 说明 |
|---------|---------|------|------|------|------|
| controlActProcess.subject.registrationRequest.terminology.id.item | 术语编码 | string | 是 | 50 | 术语唯一标识 |
| controlActProcess.subject.registrationRequest.terminology.name | 术语名称 | string | 是 | 200 | 术语中文名称 |
| controlActProcess.subject.registrationRequest.terminology.codeSystem | 术语体系 | string | 是 | - | ICD-10/ICD-9-CM/SNOMED-CT/LOINC |
| controlActProcess.subject.registrationRequest.terminology.version | 版本号 | string | 否 | 20 | 术语版本 |
| controlActProcess.subject.registrationRequest.terminology.status | 状态 | string | 是 | - | active-有效/inactive-无效/deprecated-已弃用 |

### 术语更新请求

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| controlActProcess.subject.updateRequest.terminology.id.item | 术语编码 | string | 是 | 要更新的术语编码 |
| controlActProcess.subject.updateRequest.terminology.* | 术语信息 | object | 否 | 需要更新的术语字段 |

### 术语查询请求

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| controlActProcess.queryByParameter.termId | 术语编码 | string | 否 | 按术语编码查询 |
| controlActProcess.queryByParameter.termName | 术语名称 | string | 否 | 按术语名称查询 |
| controlActProcess.queryByParameter.codeSystem | 术语体系 | string | 否 | 按编码体系查询 |

### 应答消息

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| acknowledgement.typeCode | 处理结果类型 | string | 是 | AA-成功/AE-失败/AR-拒绝 |
| acknowledgement.targetMessage.id.extension | 请求消息流水号 | string | 是 | 被应答的请求消息流水号 |
| acknowledgement.acknowledgementDetail.text | 处理结果说明 | string | 是 | 处理结果的文字说明 |
