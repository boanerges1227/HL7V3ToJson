# 第7部分：就诊信息交互服务 字段说明

**标准编号**: WS/T 846.7-2024

## 服务列表

| 服务名称 | 交互标识符 | 说明 |
|---------|-----------|------|
| 门诊挂号信息新增服务 | PRPA_IN400001UV | 用于门诊挂号信息的登记 |
| 住院就诊信息登记服务 | PRPA_IN400001UV | 用于住院患者入院登记 |
| 出院登记信息新增服务 | PRPA_IN400003UV01 | 用于住院患者出院登记 |

## 字段说明

### 消息头（公共部分）

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| messageHeader.id.root | 消息流水号根标识 | string | 是 | 固定值 2.16.156.10011.2.5.1.1 |
| messageHeader.id.extension | 消息流水号 | string | 是 | 消息唯一标识，最大50字符 |
| messageHeader.creationTime | 消息创建时间 | datetime | 是 | 格式：yyyyMMddHHmmss |
| messageHeader.interactionId.extension | 服务标识 | string | 是 | 具体服务标识代码 |
| messageHeader.processingCode | 处理代码 | string | 是 | D-调试/P-产品/T-训练 |
| messageHeader.acceptAckCode | 应答控制码 | string | 是 | AL-总是/ER-仅错误/NE-从不 |

### 门诊挂号信息新增请求

| 字段路径 | 字段名称 | 类型 | 必填 | 数据元 | 说明 |
|---------|---------|------|------|--------|------|
| controlActProcess.subject.registrationRequest.encounter.id.item | 就诊流水号 | string | 是 | - | 就诊唯一标识 |
| controlActProcess.subject.registrationRequest.encounter.patientId.item | 患者编号 | string | 是 | - | 患者唯一标识 |
| controlActProcess.subject.registrationRequest.encounter.outpatientNo | 门诊号 | string | 是 | - | 门诊就诊号 |
| controlActProcess.subject.registrationRequest.encounter.deptId | 挂号科室 | string | 是 | - | 挂号科室编号 |
| controlActProcess.subject.registrationRequest.encounter.doctorId | 挂号医生 | string | 否 | - | 指定医生工号 |
| controlActProcess.subject.registrationRequest.encounter.visitType | 就诊类型 | string | 是 | - | 普通门诊/专家门诊/急诊/特需门诊 |
| controlActProcess.subject.registrationRequest.encounter.registerTime | 挂号时间 | datetime | 是 | - | 挂号操作时间 |

### 住院就诊信息登记请求

| 字段路径 | 字段名称 | 类型 | 必填 | 数据元 | 说明 |
|---------|---------|------|------|--------|------|
| controlActProcess.subject.registrationRequest.encounter.id.item | 就诊流水号 | string | 是 | - | 就诊唯一标识 |
| controlActProcess.subject.registrationRequest.encounter.patientId.item | 患者编号 | string | 是 | - | 患者唯一标识 |
| controlActProcess.subject.registrationRequest.encounter.inpatientNo | 住院号 | string | 是 | - | 住院号 |
| controlActProcess.subject.registrationRequest.encounter.deptId | 入院科室 | string | 是 | - | 入院科室编号 |
| controlActProcess.subject.registrationRequest.encounter.wardId | 病区 | string | 是 | - | 病区编号 |
| controlActProcess.subject.registrationRequest.encounter.bedId | 床位 | string | 否 | - | 床位编号 |
| controlActProcess.subject.registrationRequest.encounter.admitTime | 入院时间 | datetime | 是 | - | 入院时间 |
| controlActProcess.subject.registrationRequest.encounter.admitDiagnosis | 入院诊断 | string | 否 | - | 入院诊断 |

### 出院登记信息新增请求

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| controlActProcess.subject.dischargeRequest.encounterId.item | 就诊流水号 | string | 是 | 就诊唯一标识 |
| controlActProcess.subject.dischargeRequest.patientId.item | 患者编号 | string | 是 | 患者唯一标识 |
| controlActProcess.subject.dischargeRequest.inpatientNo | 住院号 | string | 是 | 住院号 |
| controlActProcess.subject.dischargeRequest.dischargeTime | 出院时间 | datetime | 是 | 出院时间 |
| controlActProcess.subject.dischargeRequest.dischargeDiagnosis | 出院诊断 | string | 否 | 出院诊断 |
| controlActProcess.subject.dischargeRequest.dischargeDisposition | 出院方式 | string | 是 | 医嘱离院/医嘱转院/医嘱转社区/非医嘱离院/死亡 |

### 应答消息

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| acknowledgement.typeCode | 处理结果类型 | string | 是 | AA-成功/AE-失败/AR-拒绝 |
| acknowledgement.targetMessage.id.extension | 请求消息流水号 | string | 是 | 被应答的请求消息流水号 |
| acknowledgement.acknowledgementDetail.text | 处理结果说明 | string | 是 | 处理结果的文字说明 |
