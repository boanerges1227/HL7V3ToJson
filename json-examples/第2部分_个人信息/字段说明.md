# 第2部分：个人信息注册、查询服务 字段说明

**标准编号**: WS/T 846.2-2024

## 服务列表

| 服务名称 | 交互标识符 | 说明 |
|---------|-----------|------|
| 个人信息注册服务 | PRPA_IN201311UV02 | 用于新患者个人信息的注册 |
| 个人信息更新服务 | PRPA_IN201314UV02 | 用于已注册患者个人信息的更新 |
| 个人信息查询服务 | PRPA_IN201305UV02 | 用于查询患者个人信息 |
| 个人信息合并服务 | PRPA_IN201304UV02 | 用于合并重复的患者记录 |

## 字段说明

### 消息头（公共部分）

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| messageHeader.id.root | 消息流水号根标识 | string | 是 | 固定值 2.16.156.10011.2.5.1.1 |
| messageHeader.id.extension | 消息流水号 | string | 是 | 消息唯一标识，最大50字符 |
| messageHeader.creationTime | 消息创建时间 | datetime | 是 | 格式：yyyyMMddHHmmss |
| messageHeader.interactionId.extension | 服务标识 | string | 是 | 具体服务标识代码 |
| messageHeader.processingCode | 处理代码 | string | 是 | D-调试/P-产品/T-训练 |
| messageHeader.acceptAckCode | 应答控制码 | string | 是 | AL-总是/ER-仅错误/NE-从不 |

### 个人信息注册请求

| 字段路径 | 字段名称 | 类型 | 必填 | 数据元 | 说明 |
|---------|---------|------|------|--------|------|
| controlActProcess.subject.registrationRequest.patient.id.item | 患者编号 | string | 是 | - | 患者唯一标识 |
| controlActProcess.subject.registrationRequest.patient.idCard | 身份证件号码 | string | 否 | DE02.01.030.02 | 患者身份证号码 |
| controlActProcess.subject.registrationRequest.patient.name | 患者姓名 | string | 是 | DE02.01.039.01 | 患者真实姓名 |
| controlActProcess.subject.registrationRequest.patient.gender | 性别 | string | 是 | DE02.01.040.00 | M-男/F-女/U-未知 |
| controlActProcess.subject.registrationRequest.patient.birthTime | 出生日期 | date | 是 | DE02.01.005.00 | 格式：yyyyMMdd |
| controlActProcess.subject.registrationRequest.patient.phone | 联系电话 | string | 否 | DE02.01.010.05 | 患者电话号码 |
| controlActProcess.subject.registrationRequest.patient.address | 联系地址 | string | 否 | - | 患者居住地址 |
| controlActProcess.subject.registrationRequest.patient.healthCardNo | 居民健康卡号 | string | 否 | DE01.00.021.00 | 居民健康卡编号 |

### 个人信息更新请求

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| controlActProcess.subject.updateRequest.patient.id.item | 患者编号 | string | 是 | 要更新的患者编号 |
| controlActProcess.subject.updateRequest.patient.* | 患者信息 | object | 否 | 需要更新的患者字段 |

### 个人信息查询请求

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| controlActProcess.queryByParameter.patientId | 患者编号 | string | 否 | 按患者编号查询 |
| controlActProcess.queryByParameter.idCard | 身份证号码 | string | 否 | 按身份证号查询 |
| controlActProcess.queryByParameter.name | 患者姓名 | string | 否 | 按姓名查询 |

### 个人信息合并请求

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| controlActProcess.subject.mergeRequest.sourcePatient | 源患者 | object | 是 | 要合并的源患者记录 |
| controlActProcess.subject.mergeRequest.targetPatient | 目标患者 | object | 是 | 合并目标患者记录 |

### 应答消息

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| acknowledgement.typeCode | 处理结果类型 | string | 是 | AA-成功/AE-失败/AR-拒绝 |
| acknowledgement.targetMessage.id.extension | 请求消息流水号 | string | 是 | 被应答的请求消息流水号 |
| acknowledgement.acknowledgementDetail.text | 处理结果说明 | string | 是 | 处理结果的文字说明 |
