# 第11部分：状态信息交互服务 字段说明

**标准编号**: WS/T 846.11-2024

## 服务列表

| 服务名称 | 交互标识符 | 说明 |
|---------|-----------|------|
| 状态更新服务 | POOR_IN200920UV | 用于业务状态信息的更新 |
| 状态查询服务 | QUMT_IN020070UV01 | 用于查询业务状态信息 |

## 字段说明

### 消息头（公共部分）

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| messageHeader.id.root | 消息流水号根标识 | string | 是 | 固定值 2.16.156.10011.2.5.1.1 |
| messageHeader.id.extension | 消息流水号 | string | 是 | 消息唯一标识，最大50字符 |
| messageHeader.creationTime | 消息创建时间 | datetime | 是 | 格式：yyyyMMddHHmmss |
| messageHeader.interactionId.extension | 服务标识 | string | 是 | 具体服务标识代码 |
| messageHeader.processingCode | 处理代码 | string | 是 | D-调试/P-产品/T-训练 |
| messageHeader.acceptAckCode | 应答控制码 | string | 是 | AL-总是/ER-仅错误/NE-从不 |

### 状态更新请求

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| controlActProcess.subject.statusUpdate.businessId.item | 业务编号 | string | 是 | 要更新状态的业务记录编号 |
| controlActProcess.subject.statusUpdate.businessType | 业务类型 | string | 是 | 预约/挂号/就诊/医嘱/检查/检验/手术/出院 |
| controlActProcess.subject.statusUpdate.statusCode | 状态代码 | string | 是 | active-进行中/completed-已完成/cancelled-已取消/suspended-已暂停 |
| controlActProcess.subject.statusUpdate.statusName | 状态名称 | string | 是 | 状态中文名称 |
| controlActProcess.subject.statusUpdate.updateTime | 更新时间 | datetime | 是 | 状态更新时间 |
| controlActProcess.subject.statusUpdate.updateOperator | 操作人 | string | 否 | 执行状态更新的操作人 |
| controlActProcess.subject.statusUpdate.remark | 备注 | string | 否 | 状态更新备注说明 |

### 状态查询请求

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| controlActProcess.queryByParameter.businessId | 业务编号 | string | 否 | 按业务编号查询 |
| controlActProcess.queryByParameter.businessType | 业务类型 | string | 否 | 按业务类型查询 |
| controlActProcess.queryByParameter.patientId | 患者编号 | string | 否 | 按患者编号查询 |
| controlActProcess.queryByParameter.status | 状态代码 | string | 否 | 按状态代码查询 |
| controlActProcess.queryByParameter.updateTimeRange | 更新时间范围 | object | 否 | 按更新时间范围查询 |

### 应答消息

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| acknowledgement.typeCode | 处理结果类型 | string | 是 | AA-成功/AE-失败/AR-拒绝 |
| acknowledgement.targetMessage.id.extension | 请求消息流水号 | string | 是 | 被应答的请求消息流水号 |
| acknowledgement.acknowledgementDetail.text | 处理结果说明 | string | 是 | 处理结果的文字说明 |

## 状态码汇总

### 状态代码

| 代码 | 名称 | 说明 |
|------|------|------|
| active | 进行业务正在处理中 |
| completed | 已完成 | 业务已顺利完成 |
| cancelled | 已取消 | 业务已被取消 |
| suspended | 已暂停 | 业务处理暂停 |

### 业务类型

| 代码 | 说明 |
|------|------|
| 预约 | 预约挂号业务 |
| 挂号 | 门诊挂号业务 |
| 就诊 | 门诊/住院就诊业务 |
| 医嘱 | 医嘱开立/执行业务 |
| 检查 | 影像/超声等检查业务 |
| 检验 | 血液/体液等检验业务 |
| 手术 | 手术安排/执行业务 |
| 出院 | 住院出院业务 |
