# 第3部分：医疗卫生机构注册、查询服务 字段说明

**标准编号**: WS/T 846.3-2024

## 服务列表

| 服务名称 | 交互标识符 | 说明 |
|---------|-----------|------|
| 医疗机构注册服务 | PRPM_IN401030UV01 | 用于新医疗机构信息的注册 |
| 医疗机构更新服务 | PRPM_IN403010UV01 | 用于已注册机构信息的更新 |
| 医疗机构查询服务 | PRPM_IN406010UV01 | 用于查询医疗机构信息 |

## 字段说明

### 消息头（公共部分）

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| messageHeader.id.root | 消息流水号根标识 | string | 是 | 固定值 2.16.156.10011.2.5.1.1 |
| messageHeader.id.extension | 消息流水号 | string | 是 | 消息唯一标识，最大50字符 |
| messageHeader.creationTime | 消息创建时间 | datetime | 是 | 格式：yyyyMMddHHmmss |
| messageHeader.interactionId.extension | 服务标识 | string | 是 | 具体服务标识代码 |
| messageHeader.processingCode | 处理代码 | string | 是 | D-调试/P-产品/T-训练 |
| messageHeader.acceptAckCode | 应答控制码 | string | 是 | AL-总是/ER-仅错误/NE-从不 |

### 医疗机构注册请求

| 字段路径 | 字段名称 | 类型 | 必填 | 数据元 | 说明 |
|---------|---------|------|------|--------|------|
| controlActProcess.subject.registrationRequest.organization.id.item | 机构编号 | string | 是 | - | 医疗机构唯一标识 |
| controlActProcess.subject.registrationRequest.organization.name | 机构名称 | string | 是 | DE08.10.026.00 | 医疗机构名称 |
| controlActProcess.subject.registrationRequest.organization.type | 机构类型 | string | 是 | - | 医院/社区卫生服务中心/诊所 |
| controlActProcess.subject.registrationRequest.organization.address | 机构地址 | string | 否 | - | 医疗机构地址 |
| controlActProcess.subject.registrationRequest.organization.phone | 联系电话 | string | 否 | - | 机构联系电话 |
| controlActProcess.subject.registrationRequest.department.id.item | 科室编号 | string | 是 | - | 科室唯一标识 |
| controlActProcess.subject.registrationRequest.department.name | 科室名称 | string | 是 | DE08.10.026.00 | 科室名称 |
| controlActProcess.subject.registrationRequest.department.type | 科室类型 | string | 是 | - | 内科/外科/妇产科/儿科等 |

### 医疗机构更新请求

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| controlActProcess.subject.updateRequest.organization.id.item | 机构编号 | string | 是 | 要更新的机构编号 |
| controlActProcess.subject.updateRequest.organization.* | 机构信息 | object | 否 | 需要更新的机构字段 |

### 医疗机构查询请求

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| controlActProcess.queryByParameter.orgId | 机构编号 | string | 否 | 按机构编号查询 |
| controlActProcess.queryByParameter.orgName | 机构名称 | string | 否 | 按机构名称查询 |
| controlActProcess.queryByParameter.deptId | 科室编号 | string | 否 | 按科室编号查询 |

### 应答消息

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| acknowledgement.typeCode | 处理结果类型 | string | 是 | AA-成功/AE-失败/AR-拒绝 |
| acknowledgement.targetMessage.id.extension | 请求消息流水号 | string | 是 | 被应答的请求消息流水号 |
| acknowledgement.acknowledgementDetail.text | 处理结果说明 | string | 是 | 处理结果的文字说明 |
