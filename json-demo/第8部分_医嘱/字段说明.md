# 第8部分：医嘱信息交互服务 字段说明

**标准编号**: WS/T 846.8-2024

## 服务列表

| 服务名称 | 交互标识符 | 说明 |
|---------|-----------|------|
| 医嘱信息新增服务 | POOR_IN200901UV | 用于医嘱信息的新增 |
| 医嘱信息更新服务 | POOR_IN200902UV | 用于医嘱信息的更新 |
| 医嘱信息查询服务 | QUMT_IN020030UV01 | 用于查询医嘱信息 |

## 字段说明

### 消息头（公共部分）

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| messageHeader.id.root | 消息流水号根标识 | string | 是 | 固定值 2.16.156.10011.2.5.1.1 |
| messageHeader.id.extension | 消息流水号 | string | 是 | 消息唯一标识，最大50字符 |
| messageHeader.creationTime | 消息创建时间 | datetime | 是 | 格式：yyyyMMddHHmmss |
| messageHeader.interactionId.extension | 服务标识 | string | 是 | 具体服务标识代码 |
| messageHeader.processingCode | 处理代码 | string | 是 | D-调试/P-产品/T-训练 |
| messageHeader.acceptAckCode | 应答控制码 | string | 是 | AL-总是/ER-仅错误/NE-从不 |

### 医嘱信息新增请求

| 字段路径 | 字段名称 | 类型 | 必填 | 数据元 | 说明 |
|---------|---------|------|------|--------|------|
| controlActProcess.subject.order.author.time | 开立时间 | datetime | 是 | DE08.50.033.00 | 医嘱开立时间 |
| controlActProcess.subject.order.author.signatureText | 开立医师签名 | string | 否 | DE02.01.039.00 | 医师电子签名 |
| controlActProcess.subject.order.author.assignedEntity.id.item | 开立医师工号 | string | 否 | - | 开立医嘱的医师工号 |
| controlActProcess.subject.order.author.assignedEntity.organization.id.item | 开立科室编码 | string | 否 | - | 开立科室 |
| controlActProcess.subject.order.components[].id.item | 医嘱编号 | string | 是 | - | 医嘱唯一标识 |
| controlActProcess.subject.order.components[].code.displayName | 医嘱类型 | string | 是 | - | 药品类/检查类/检验类/手术类/治疗类 |
| controlActProcess.subject.order.components[].text | 医嘱内容 | string | 是 | DE06.00.288.00 | 医嘱详细内容 |
| controlActProcess.subject.order.components[].statusCode | 医嘱状态 | string | 是 | - | active-有效/completed-完成/cancelled-取消 |
| controlActProcess.subject.order.components[].effectiveTime | 有效期间 | object | 否 | - | 医嘱开始/结束时间 |
| controlActProcess.subject.order.components[].routeCode | 用药途径 | string | 否 | DE06.00.134.00 | 药物使用途径 |
| controlActProcess.subject.order.components[].doseQuantity | 次剂量 | object | 否 | DE08.50.023.00 | 每次用药剂量 |
| controlActProcess.subject.order.components[].medication.name | 药物名称 | string | 否 | DE08.50.022.00 | 药物名称 |
| controlActProcess.subject.order.components[].location.id.item | 执行科室 | string | 否 | - | 执行科室编码 |
| controlActProcess.subject.order.encounter.id.item | 就诊流水号 | string | 是 | - | 关联的就诊记录 |
| controlActProcess.subject.order.encounter.patientId.item | 患者编号 | string | 是 | - | 患者唯一标识 |

### 医嘱信息更新请求

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| controlActProcess.subject.order.components[].id.item | 医嘱编号 | string | 是 | 要更新的医嘱编号 |
| controlActProcess.subject.order.components[].statusCode | 医嘱状态 | string | 是 | 更新后的状态 |

### 医嘱信息查询请求

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| controlActProcess.queryByParameter.actId | 医嘱编号 | string | 否 | 按医嘱编号查询 |
| controlActProcess.queryByParameter.patientId | 患者编号 | string | 否 | 按患者编号查询 |
| controlActProcess.queryByParameter.authorId | 开立医师 | string | 否 | 按开立医师查询 |
| controlActProcess.queryByParameter.effectiveTime | 有效期间 | object | 否 | 按时间范围查询 |

### 应答消息

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| acknowledgement.typeCode | 处理结果类型 | string | 是 | AA-成功/AE-失败/AR-拒绝 |
| acknowledgement.targetMessage.id.extension | 请求消息流水号 | string | 是 | 被应答的请求消息流水号 |
| acknowledgement.acknowledgementDetail.text | 处理结果说明 | string | 是 | 处理结果的文字说明 |
