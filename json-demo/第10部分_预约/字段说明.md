# 第10部分：预约信息交互服务 字段说明

**标准编号**: WS/T 846.10-2024

## 服务列表

| 服务名称 | 交互标识符 | 说明 |
|---------|-----------|------|
| 预约申请服务 | POOR_IN200910UV | 用于预约挂号申请 |
| 预约取消服务 | POOR_IN200911UV | 用于取消已预约的挂号 |
| 预约查询服务 | QUMT_IN020050UV01 | 用于查询预约信息 |

## 字段说明

### 消息头（公共部分）

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| messageHeader.id.root | 消息流水号根标识 | string | 是 | 固定值 2.16.156.10011.2.5.1.1 |
| messageHeader.id.extension | 消息流水号 | string | 是 | 消息唯一标识，最大50字符 |
| messageHeader.creationTime | 消息创建时间 | datetime | 是 | 格式：yyyyMMddHHmmss |
| messageHeader.interactionId.extension | 服务标识 | string | 是 | 具体服务标识代码 |
| messageHeader.processingCode | 处理代码 | string | 是 | D-调试/P-产品/T-训练 |
| messageHeader.acceptAckCode | 应答控制码 | string | 是 | AL-总是/ER-仅错误/NE-从不 |

### 预约申请请求

| 字段路径 | 字段名称 | 类型 | 必填 | 数据元 | 说明 |
|---------|---------|------|------|--------|------|
| controlActProcess.subject.appointment.id.item | 预约流水号 | string | 是 | - | 预约唯一标识 |
| controlActProcess.subject.appointment.patientId.item | 患者编号 | string | 是 | - | 预约患者 |
| controlActProcess.subject.appointment.patientName | 患者姓名 | string | 是 | DE02.01.039.01 | 患者姓名 |
| controlActProcess.subject.appointment.deptId | 预约科室 | string | 是 | - | 预约科室编码 |
| controlActProcess.subject.appointment.deptName | 科室名称 | string | 是 | DE08.10.026.00 | 预约科室名称 |
| controlActProcess.subject.appointment.doctorId | 预约医生 | string | 否 | - | 指定医生工号 |
| controlActProcess.subject.appointment.doctorName | 医生姓名 | string | 否 | - | 指定医生姓名 |
| controlActProcess.subject.appointment.appointmentDate | 预约日期 | date | 是 | - | 预约就诊日期 |
| controlActProcess.subject.appointment.appointmentTime | 预约时段 | string | 是 | - | 上午/下午/晚间 |
| controlActProcess.subject.appointment.visitType | 就诊类型 | string | 是 | - | 普通门诊/专家门诊/特需门诊 |
| controlActProcess.subject.appointment.contactPhone | 联系电话 | string | 是 | DE02.01.010.05 | 患者联系电话 |
| controlActProcess.subject.appointment.createTime | 预约时间 | datetime | 是 | - | 预约操作时间 |

### 预约取消请求

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| controlActProcess.subject.cancelRequest.appointmentId.item | 预约流水号 | string | 是 | 要取消的预约编号 |
| controlActProcess.subject.cancelRequest.cancelReason | 取消原因 | string | 否 | 取消预约的原因 |
| controlActProcess.subject.cancelRequest.cancelTime | 取消时间 | datetime | 是 | 取消操作时间 |

### 预约查询请求

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| controlActProcess.queryByParameter.appointmentId | 预约流水号 | string | 否 | 按预约编号查询 |
| controlActProcess.queryByParameter.patientId | 患者编号 | string | 否 | 按患者编号查询 |
| controlActProcess.queryByParameter.deptId | 科室编号 | string | 否 | 按科室编号查询 |
| controlActProcess.queryByParameter.appointmentDate | 预约日期 | date | 否 | 按预约日期查询 |
| controlActProcess.queryByParameter.status | 预约状态 | string | 否 | active-已预约/completed-已就诊/cancelled-已取消 |

### 应答消息

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| acknowledgement.typeCode | 处理结果类型 | string | 是 | AA-成功/AE-失败/AR-拒绝 |
| acknowledgement.targetMessage.id.extension | 请求消息流水号 | string | 是 | 被应答的请求消息流水号 |
| acknowledgement.acknowledgementDetail.text | 处理结果说明 | string | 是 | 处理结果的文字说明 |
