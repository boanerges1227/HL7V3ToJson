# 第6部分：文档注册、查询服务 字段说明

**标准编号**: WS/T 846.6-2024

## 服务列表

| 服务名称 | 交互标识符 | 说明 |
|---------|-----------|------|
| 文档注册服务 | RCMR_IN000002UV02 | 用于医疗文档的注册 |
| 文档查询服务 | RCMR_IN000031UV01 | 用于查询医疗文档信息 |

## 字段说明

### 消息头（公共部分）

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| messageHeader.id.root | 消息流水号根标识 | string | 是 | 固定值 2.16.156.10011.2.5.1.1 |
| messageHeader.id.extension | 消息流水号 | string | 是 | 消息唯一标识，最大50字符 |
| messageHeader.creationTime | 消息创建时间 | datetime | 是 | 格式：yyyyMMddHHmmss |
| messageHeader.interactionId.extension | 服务标识 | string | 是 | 具体服务标识代码 |
| messageHeader.processingCode | 处理代码 | string | 是 | D-调试/P-产品/T-训练 |
| messageHeader.acceptAckCode | 应答控制码 | string | 是 | AL-总是/ER-仅错误/NE-从不 |

### 文档注册请求

| 字段路径 | 字段名称 | 类型 | 必填 | 长度 | 说明 |
|---------|---------|------|------|------|------|
| controlActProcess.subject.registrationRequest.document.id.item | 文档编号 | string | 是 | 50 | 医疗文档唯一标识 |
| controlActProcess.subject.registrationRequest.document.title | 文档标题 | string | 是 | 200 | 文档标题 |
| controlActProcess.subject.registrationRequest.document.type | 文档类型 | string | 是 | - | 入院记录/病程记录/手术记录等 |
| controlActProcess.subject.registrationRequest.document.patientId | 患者编号 | string | 是 | - | 文档所属患者 |
| controlActProcess.subject.registrationRequest.document.authorId | 作者工号 | string | 是 | - | 文档创建者 |
| controlActProcess.subject.registrationRequest.document.createTime | 创建时间 | datetime | 是 | - | 文档创建时间 |
| controlActProcess.subject.registrationRequest.document.content | 文档内容 | string | 否 | - | 文档正文内容 |

### 文档查询请求

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| controlActProcess.queryByParameter.docId | 文档编号 | string | 否 | 按文档编号查询 |
| controlActProcess.queryByParameter.patientId | 患者编号 | string | 否 | 按患者编号查询 |
| controlActProcess.queryByParameter.docType | 文档类型 | string | 否 | 按文档类型查询 |
| controlActProcess.queryByParameter.createTimeRange | 创建时间范围 | object | 否 | 按时间范围查询 |

### 应答消息

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| acknowledgement.typeCode | 处理结果类型 | string | 是 | AA-成功/AE-失败/AR-拒绝 |
| acknowledgement.targetMessage.id.extension | 请求消息流水号 | string | 是 | 被应答的请求消息流水号 |
| acknowledgement.acknowledgementDetail.text | 处理结果说明 | string | 是 | 处理结果的文字说明 |
