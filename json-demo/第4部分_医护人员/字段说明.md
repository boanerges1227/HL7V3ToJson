# 第4部分：医疗卫生人员注册、查询服务 字段说明

**标准编号**: WS/T 846.4-2024

## 服务列表

| 服务名称 | 交互标识符 | 说明 |
|---------|-----------|------|
| 医护人员注册服务 | PRPM_IN301010UV01 | 用于新医护人员信息的注册 |
| 医护人员更新服务 | PRPM_IN303010UV01 | 用于已注册人员信息的更新 |
| 医护人员查询服务 | PRPM_IN306010UV01 | 用于查询医护人员信息 |

## 字段说明

### 消息头（公共部分）

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| messageHeader.id.root | 消息流水号根标识 | string | 是 | 固定值 2.16.156.10011.2.5.1.1 |
| messageHeader.id.extension | 消息流水号 | string | 是 | 消息唯一标识，最大50字符 |
| messageHeader.creationTime | 消息创建时间 | datetime | 是 | 格式：yyyyMMddHHmmss |
| messageHeader.interactionId.extension | 服务标识 | string | 是 | 具体服务标识代码 |
| messageHeader.processingCode | 处理代码 | string | 是 | D-调试/P-产品/T-训练 |
| messageHeader.acceptAckCode | 应答控制码 | string | 是 | AL-总是/ER-仅错误/NE-从不 |

### 医护人员注册请求

| 字段路径 | 字段名称 | 类型 | 必填 | 数据元 | 说明 |
|---------|---------|------|------|--------|------|
| controlActProcess.subject.registrationRequest.person.id.item | 人员工号 | string | 是 | - | 医护人员唯一标识 |
| controlActProcess.subject.registrationRequest.person.name | 姓名 | string | 是 | DE02.01.039.00 | 医护人员姓名 |
| controlActProcess.subject.registrationRequest.person.gender | 性别 | string | 是 | DE02.01.040.00 | M-男/F-女 |
| controlActProcess.subject.registrationRequest.person.birthTime | 出生日期 | date | 否 | DE02.01.005.00 | 格式：yyyyMMdd |
| controlActProcess.subject.registrationRequest.person.title | 职称 | string | 否 | DE08.30.031.00 | 主任医师/副主任医师/主治医师等 |
| controlActProcess.subject.registrationRequest.person.dept.id.item | 所属科室编号 | string | 是 | - | 医护人员所属科室 |
| controlActProcess.subject.registrationRequest.person.dept.name | 科室名称 | string | 否 | DE08.10.026.00 | 所属科室名称 |
| controlActProcess.subject.registrationRequest.person.phone | 联系电话 | string | 否 | - | 医护人员电话 |

### 医护人员更新请求

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| controlActProcess.subject.updateRequest.person.id.item | 人员工号 | string | 是 | 要更新的人员工号 |
| controlActProcess.subject.updateRequest.person.* | 人员信息 | object | 否 | 需要更新的人员字段 |

### 医护人员查询请求

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| controlActProcess.queryByParameter.personId | 人员工号 | string | 否 | 按工号查询 |
| controlActProcess.queryByParameter.personName | 姓名 | string | 否 | 按姓名查询 |
| controlActProcess.queryByParameter.deptId | 科室编号 | string | 否 | 按科室查询 |
| controlActProcess.queryByParameter.gender | 性别 | string | 否 | 按性别查询 |

### 应答消息

| 字段路径 | 字段名称 | 类型 | 必填 | 说明 |
|---------|---------|------|------|------|
| acknowledgement.typeCode | 处理结果类型 | string | 是 | AA-成功/AE-失败/AR-拒绝 |
| acknowledgement.targetMessage.id.extension | 请求消息流水号 | string | 是 | 被应答的请求消息流水号 |
| acknowledgement.acknowledgementDetail.text | 处理结果说明 | string | 是 | 处理结果的文字说明 |
